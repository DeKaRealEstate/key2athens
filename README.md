# Key2Athens

Key2Athens is a real estate lottery crowdfunding platform. Users can buy €20 tickets for a chance to win a fully renovated apartment in Athens, Greece. The site explains the concept, shows the apartment, tracks funding progress, and displays recent registrants.

## Quick Start

1. Clone the repository:
   ```bash
   git clone https://github.com/DeKaRealEstate/key2athens.git
   ```
2. Navigate to the project directory:
   ```bash
   cd key2athens
   ```
3. Install dependencies:
   ```bash
   npm install
   ```
4. Start the server:
   ```bash
   npm start
   ```
5. Visit [http://localhost:3000](http://localhost:3000) in your browser.

## Features

- Landing page with apartment details and progress bar
- Registration form (demo: in-memory storage)
- List of recent registrants
- Simple, modern UI with PicoCSS
